# 🖱️ Drag and Drop

Two drag-and-drop demos built with the native **HTML5 Drag and Drop API**:

1. **List mover** — drag list items between two boxes.
2. **File drop zone** — drop any file to preview and download it.

## ✨ Features

- Drag list items back and forth between two containers
- Drop **any file type** onto the drop area
- **Image files** are previewed as images
- **Text files** are previewed as text
- Other file types show their name and type
- **Download** link for the first dropped file
- Highlight effect while dragging over the drop area

## 🛠️ Built With

- HTML5 (Drag and Drop API)
- CSS3
- JavaScript (Vanilla, FileReader, Blob URLs)
- [Font Awesome](https://fontawesome.com/)
